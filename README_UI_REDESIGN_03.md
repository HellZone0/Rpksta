# UI Redesign 03 — Clean Modern

Perombakan visual khusus CSS. Fitur aplikasi dan dataset dipertahankan.

Prinsip desain:
- Mengurangi gradient, glassmorphism, glow, dan shadow berat.
- Radius lebih kecil dan konsisten.
- Warna lebih tenang dengan aksen biru seperlunya.
- Hierarki tipografi lebih jelas.
- Tombol dan kartu lebih padat seperti aplikasi belajar nyata.
- Mobile navigation tetap dipertahankan.
- `script.js`, `data/vocabulary.json`, dan `data/chapters.json` tidak diubah.
