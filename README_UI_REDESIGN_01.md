# UI Redesign 01

Perombakan visual khusus proyek Website EPS-TOPIK Vocabulary Quiz.

Yang dipertahankan:
- Data Bab 1–30 dan vocabulary.json.
- Search global, filter Bab/kategori.
- Quiz semua mode dan aturan 2 kesempatan.
- Feedback benar/salah dan auto-next.
- Listening dan jeda `/`.
- Flashcard flip.
- Statistik, XP, level, streak, achievement, review.
- Dark/light mode dan localStorage.
- Mobile bottom navigation.

Perubahan hanya pada tampilan/CSS. `script.js` dan data vocabulary tidak diubah.
