# UI Redesign V4 — Clean Study Dashboard

Implementasi design brief terbaru untuk Website EPS-TOPIK Vocabulary Quiz.

## Yang diubah
- Visual diarahkan ke clean Korean study dashboard.
- Gradient background dihapus.
- Glassmorphism/backdrop blur dihapus.
- Glow dekoratif dihapus.
- Hero dibuat lebih proporsional untuk aplikasi belajar.
- Card, radius, border, dan shadow dibuat lebih tenang.
- Typography dan spacing dijadikan hierarchy utama.
- Mobile bottom navigation dibuat solid dan ringkas.
- Focus state dan reduced-motion dipertahankan.
- Light/Dark mode tetap menggunakan CSS variables.

## Yang dipertahankan
- `script.js`
- `data/vocabulary.json` — 2.355 entri
- `data/chapters.json` — 30 bab
- Quiz engine, flashcard, listening, progress, localStorage, PWA, dan fitur belajar lainnya.

Tidak ada perubahan pada engine quiz atau dataset vocabulary.
